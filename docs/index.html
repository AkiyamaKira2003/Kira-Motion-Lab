ENGINEERING PRINCIPLES

A good animation knows
when not to move.

01 /Compositor first

Favor transform and opacity over layout-affecting changes to reduce rendering work.

02 /Respect the user

Honor reduced-motion preference by default and make motion controls easy to find.

03 /Cleanup matters

Cancel pending frames and detach event listeners when a component is destroyed.
